# Мастерская «Точное время» — Система учёта ремонта часов

> Курсовой проект: информационная система для автоматизации работы часовой мастерской на C# WinForms + SQL Server.

---

## Описание проекта

**«Точное время»** — это десктопное приложение для автоматизации процессов приёма, обработки и выдачи заказов на ремонт часов. Система охватывает полный цикл работы мастерской: от создания заказа до формирования отчётов и управления складом запчастей.

---

## Функционал

### Авторизация и разграничение доступа
- **Ролевая модель** с тремя уровнями доступа:
  - **Администратор** — полный доступ, настройки системы, управление пользователями
  - **Менеджер** — приём заказов, работа с клиентами, просмотр отчётов
  - **Мастер** — работа со своими заказами, доступ к складу запчастей

### Управление заказами
- Создание и редактирование заказов на ремонт
- Автоматическая генерация номера заказа
- Детальная информация о часах: тип, механизм, марка, модель, заводской номер
- Описание неисправности
- Назначение мастера и установка предварительной даты готовности
- Цветовая индикация статусов заказов в таблице

### Управление клиентами
- База клиентов с ФИО, телефоном, email и адресом
- Валидация полей: маска телефона `+7 (999) 000-0000`, проверка формата email
- Поиск клиентов по ФИО, телефону или email
- Защита от удаления клиентов с активными заказами

### Склад запчастей
- Учёт запчастей по категориям
- Контроль остатков: **автоматическая цветовая индикация** статуса запасов:
  - **НОРМА** — достаточно запасов
  - **НИЗКИЙ** — остаток ниже 150% от минимума
  - **КРИТИЧЕСКИЙ** — остаток на уровне минимума или ниже
- Операция «Приход» для увеличения количества на складе
- Защита от удаления запчастей, используемых в заказах

### Работы и запчасти в заказе
- Добавление выполненных работ с указанием стоимости
- Выбор запчастей из склада с контролем доступного количества
- Автоматический пересчёт итоговой стоимости заказа
- **Автоматическая смена статуса** заказа на «В работе» при добавлении первой работы (через триггеры БД)

### Отчёты
- **Отчёт по заказам** — статистика по статусам за период
- **Финансовый отчёт** — доходы, расходы, прибыль
- **Отчёт по складу** — критические и низкие остатки
- **Отчёт по мастерам** — эффективность выполнения заказов
- **Экспорт в CSV** — сохранение любого отчёта в файл

### Поиск заказов
- Быстрый поиск по номеру заказа (поддержка форматов `З-001` или просто `1`)
- Поиск по телефону клиента
- Фильтрация по статусу и дате приёма

### Настройки и обслуживание
- Настройки компании (название, адрес, контакты)
- Проверка подключения к базе данных
- **Архивация старых заказов** — автоматическое удаление выполненных заказов с истёкшим гарантийным сроком

## Требования к базе данных

Для работы приложения требуется SQL Server с базой данных `WatchRepairDB`, содержащей следующие сущности:

**Основные таблицы:**
- `Users`, `Roles` — пользователи и роли
- `Clients` — клиенты
- `Orders`, `OrderStatuses` — заказы и их статусы
- `OrderWorks` — выполненные работы по заказам
- `OrderParts` — использованные запчасти
- `Parts`, `PartCategories` — запчасти и категории
- `WatchTypes`, `MechanismTypes` — справочники типов часов и механизмов
- `Payments`, `Expenses` — платежи и расходы

**Вспомогательные объекты:**
- Представления (`vw_OrdersSimple` и др.)
- Хранимые процедуры (`sp_CountOrdersByStatus`, `sp_GetMasterPerformanceReport`)
- Триггеры (`trg_UpdateOrderStatusOnWorkComplete` и др.)

> **Важно:** перед запуском убедитесь, что строка подключения в `DatabaseHelper.cs` указывает на ваш сервер:
> ```csharp
> private static string connectionString = @"Server=DESKTOP-JO2O3M6;Database=WatchRepairDB;Trusted_Connection=True;";
> ```

## Запуск проекта

1. Убедитесь, что установлен **SQL Server** и создана база данных `WatchRepairDB`
2. Откройте решение в **Visual Studio**
3. При необходимости измените строку подключения в `DatabaseHelper.cs`
4. Соберите проект (`Ctrl+Shift+B`)
5. Запустите приложение (`F5`)
